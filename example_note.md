This is an example note with one of every card, to show what you can do.

You can import this file directly into the NeuraCache app to see the result
(No Ads, No Signup, Generous Free Tier, Offline)

NeuraCache can read single files or walk a whole folder in search of cards. This works great with second brain tools like Obsidian and Logseq.
Everything that is not a card, like this paragraph, stays a note.

## One-line cards

Let's start with some micro cards:

Who was the first president of the USA? :: George Washington ⚡️

You can sort micro cards into decks by adding tags:

How many people are bitten by snakes each year? :: 5.3M ⚡️ #nature #travel
How many people die each year from snake bites? :: ~130k ⚡️ #nature #travel

Instead of ⚡️ you can also use 🧠 or the flashcard tag:

What is the capital of Peru? :: Lima #flashcard #geography

For a one-line spaced repetition card, use the spaced tag:

"We are what we repeatedly do" #spaced

and you can group these cards into decks with tags too:

"Excellence is not an act but a habit" #spaced #quotes

## Regular cards

Now some bigger cards. Several lines, LaTeX and images are all fine 👍

The question and the flashcard tag go on one line, the answer goes below, and a horizontal line ends the card.

Radii of stable orbits in the Bohr model #flashcard #physics

$$a_0  = \frac{{ \hbar ^2}}{{m_e ke^2}}$$
(you can also inline) $\Delta E = h\nu$ and $c = \lambda \nu$

- - -

The same works for longer spaced repetition cards:

#spaced #quotes
"We are what we repeatedly do. Excellence, then, is not an act, but a habit."

## Two-sided cards

When the question needs more than one line, start with the tag alone. The question runs to the first horizontal line, the answer to the second.

#flashcard #git

What does this command do?

```
git clean -nfd
```

- - -

It lists the untracked files and folders it would remove.

- `n` shows the result first
- `f` files
- `d` directories

- - -

## Multiple choice

A card whose answer is a task list with exactly one item ticked becomes a multiple-choice card. The ticked item is the right answer.

Which planet is the largest? #flashcard #space

- [ ] Earth
- [x] Jupiter
- [ ] Saturn
- [ ] Neptune
- [ ] Uranus

- - -

You can write more than three wrong answers. Each review picks three of them.

## Tag groups

A tag group gives its tags to every card below it, so you don't have to repeat them.

#tags #cats #animals

Top speed of a cat :: 30 mph ⚡️
How much of a tiger is a house cat? :: 95.6% of their DNA is shared 🧠
